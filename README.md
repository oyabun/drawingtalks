# Drawing Talks

[@oyabun](https://github.com/oyabun)'s sketchnote notebooks on a 3D bookshelf: each notebook is a book you take off the shelf, open and leaf through. Each sketchnote fills a full two-page spread.

- `site/index.html`: 3D bookshelf (three.js)
- `site/classic.html`: classic CSS 3D view

The interface is in English and Spanish (`site/i18n.js`). It follows the browser language; the toggle in the top-right corner or `?lang=en` / `?lang=es` switches it.

## Links

| URL | Opens |
| --- | --- |
| `#/tarugo-2024` | the notebook, closed |
| `#/tarugo-2024/0` | the title page |
| `#/tarugo-2024/3` | sketchnote 3 |
| `#/tarugo-2024/end` | the last sketchnote |

## Structure

```
notebooks/<Notebook>/       originals (kept out of the repo, except info.json)
  cover.png                 front cover; without it the first sketchnote is used
  back.png                  back cover; without it one is generated from info.json
  *.png / *.jpg             sketchnotes, ordered by the number in the file name
  info.json                 back cover and wall details
  assets/
    wallpaper.png           wall while the notebook is selected
    poster-*.png            satin posters pasted on the wall
site/                       the published site (img/ and notebooks.json come from the build)
tools/                      build, watcher and local server
```

### info.json

`node tools/make-info.js` creates it for notebooks that don't have one; existing files are never touched.

```json
{
  "event": "Tarugo",
  "edition": "2024",
  "date": "2024",
  "venue": "La Nave (Madrid)",
  "url": "",
  "description": { "en": "…", "es": "…" },
  "wallpaper": "wallpaper.png",
  "author": "@oyabun",
  "sketchnotes": 7,
  "talks": [
    { "sketchnote": 1, "file": "…png", "title": "…", "speaker": "…", "url": "" }
  ],
  "posters": {
    "poster-movie.png": { "x": -3, "y": 2.8, "height": 2.4, "rotation": -3 }
  }
}
```

- Text fields (`date`, `venue`, `url`, `description`, a talk's `title`) can be a plain string or `{ "en": "…", "es": "…" }` to show a different text in each language.
- `talks` follows the sketchnotes in order; the back cover lists them as "title — speaker".
- `wallpaper`: looked up in the notebook folder and in `assets/`; `""` keeps the aged paper.
- `posters` is optional. Without it, posters are laid out around the shelf automatically. Units are wall units: the shelf sits at `y = 0.47` and a book is 1.09 × 1.56; `rotation` is in degrees.
- Use wallpapers 3000–4000 px wide; the build caps them at 3840 px.

## Development

```bash
cd tools
npm install
npm run build     # generates site/img and site/notebooks.json (incremental)
npm run watch     # rebuilds whenever notebooks/ changes
npm run serve     # http://localhost:8080
```

The 3D renderer (`site/3d/bookshelfRenderer.js`) is generated by `site/3d/patch_renderer.py` from ThreeUI's original; the changes are listed in [`site/3d/PATCHES.md`](site/3d/PATCHES.md).
